# Research Project Init

Set up a research project so that every result — numbers, figures, and the
report itself — can be regenerated from scratch with a single command.

## Core principles

1. **pixi manages all dependencies.** Dependencies come mainly from PyPI
   (`[pypi-dependencies]`); use conda-forge (`[dependencies]`) only for things
   PyPI can't provide well (e.g. `python` itself, compilers, CUDA). Always
   commit `pixi.lock` — it is what makes the environment reproducible.
2. **Everything is reproducible, especially the report.** The report is
   *generated by a Python script*, never hand-edited. Figures are produced by
   code, saved artifacts are derived from raw results, and a single
   `pixi run report` rebuilds the whole thing.
3. **Graphics and images use plotly or cairn-plot**
   (https://github.com/doeringchristian/cairn-plot — not on PyPI, install
   from git). cairn-plot generates self-contained offline HTML reports and wraps plotly
   figures (`cp.Figure`), images (`cp.Image`), tables, line/scatter/heatmap
   plots, point clouds, and meshes. Prefer cairn-plot's `Report` for report
   generation; use plotly directly for figures and pass them through.

## Project layout

```
project/
├── pixi.toml          # workspace, tasks, dependencies
├── pixi.lock          # committed — reproducibility
├── .envrc             # direnv: auto-activate the pixi env
├── .gitignore         # ignore .pixi/, results/, report.html
├── src/<pkg>/         # reusable code (optional, as the project grows)
├── experiments/       # scripts that produce results into results/
├── results/           # generated data (git-ignored; regenerable)
└── report.py          # generates report.html from results/
```

## pixi setup

If no `pixi.toml` exists: `pixi init --format pixi`. Then configure:

```toml
[workspace]
channels = ["conda-forge"]
name = "<project>"
platforms = ["linux-64"]

[dependencies]
python = "3.12.*"        # pin the interpreter via conda-forge

[pypi-dependencies]
numpy = "*"
plotly = "*"
# not on PyPI — install from git; [media] extra → plotly + Pillow support
cairn-plot = { git = "https://github.com/doeringchristian/cairn-plot", extras = ["media"] }

[tasks]
report = "python report.py"
```

- Add PyPI packages with `pixi add --pypi <pkg>`; conda packages with `pixi add <pkg>`;
  git packages with `pixi add --pypi "<pkg>[extras] @ git+https://github.com/<owner>/<repo>"`.
- Encode every runnable step as a pixi task (`experiment`, `report`, `all`),
  and chain them with `depends-on` so `pixi run all` reproduces everything:

```toml
[tasks]
experiment = "python experiments/run.py"
report = { cmd = "python report.py", depends-on = ["experiment"] }
```

## direnv (.envrc)

Add a `.envrc` so entering the project directory activates the pixi
environment automatically:

```sh
watch_file pixi.lock
eval "$(pixi shell-hook)"
```

Then run `direnv allow`.

## Report generation (cairn-plot)

`report.py` reads results from `results/` and emits a self-contained
`report.html`:

```python
import cairn_plot as cp
import plotly.express as px

report = (
    cp.report("Project Report")
    .md("# Results")
    .add(cp.Line({"loss": loss_curve}))          # native plot
    .add(cp.Figure(px.scatter(df, x="a", y="b")))  # plotly passthrough
    .add(cp.Image(img_array))                      # images
)
report.save("report.html")
```

Useful components: `cp.Line`, `cp.Scatter`, `cp.Bar`, `cp.Histogram`,
`cp.Heatmap`, `cp.Image`, `cp.Table`, `cp.Figure` (plotly), `cp.PointCloud`,
`cp.Mesh`, `cp.Volume`; compose with grids and `compare(...)` for
side-by-side views; interleave prose with `.md("...")`.

## Reproducibility checklist

- [ ] `pixi.lock` committed; `.pixi/` git-ignored
- [ ] Random seeds fixed and recorded in experiment scripts
- [ ] `results/` regenerable from scripts (git-ignored, or use git-lfs if kept)
- [ ] `report.html` produced only by `pixi run report`, never edited by hand
- [ ] A fresh clone reproduces everything with `pixi install && pixi run all`
